# 💰 ButceTakipProgrami - Gelir-Gider Yönetim Sistemi

Kullanıcıların günlük harcamalarını ve kazançlarını anlık olarak takip edebileceği, bütçe dengelerini sayfa yenilenmeden izleyebileceği reaktif bir bütçe yönetim uygulamasıdır.

## 🛠️ Kullanılan Teknolojiler
* **C# 13** & .NET 9.0 (Blazor Server Architecture)
* HTML5 & Bootstrap CSS (Görsel Tasarım)

## 🚀 Ne Yapıyor?
* Sayfa yenilenmeden anlık gelir ve gider ekleme/silme süreçlerini yönetir.
* Toplam geliri, gideri ve kalan net kasayı otomatik hesaplar.
* Blazor InteractiveServer mimarisi kullanarak reaktif bir kullanıcı deneyimi sunar.
